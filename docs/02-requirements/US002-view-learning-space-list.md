# US002: 查看学习空间列表

## 用户故事
作为用户，我想要查看我的所有学习空间，以便我可以快速访问不同的知识领域。

## 功能描述
用户可以查看自己创建的所有学习空间列表，支持分页、排序和搜索功能。

## 详细需求

### 1. 获取学习空间列表
- 用户可以获取自己的所有学习空间
- 默认按更新时间倒序排列
- 支持按创建时间排序
- 支持按名称字母顺序排序

### 2. 分页功能
- 支持分页查询，默认每页10条记录
- 可自定义每页记录数（1-100条）
- 返回总记录数和总页数
- 支持跳转到指定页码

### 3. 搜索功能
- 支持按学习空间名称进行模糊搜索
- 搜索不区分大小写
- 搜索结果按匹配度排序

### 4. 过滤功能
- 支持按状态（激活/归档）过滤
- 可选择是否包含已归档的学习空间

### 5. 统计信息
- 显示每个学习空间的基本信息（名称、描述、创建时间、更新时间）
- 显示每个学习空间的来源内容数量
- 显示每个学习空间的学习资料数量

## 验收标准
1. 用户能够获取自己的学习空间列表
2. 列表按指定排序规则正确排序
3. 分页功能正常工作，能正确获取指定范围的数据
4. 搜索功能能够找到匹配的学习空间
5. 过滤功能能够正确筛选结果
6. 每页能正确显示统计信息

## 非功能性需求
1. 响应时间：在500ms内返回结果
2. 支持最多10000个学习空间的列表查询
3. 支持高并发访问

## 技术实现考虑
- 后端相关，与前端无关
- 需要考虑数据库查询性能优化
- 需要实现适当的索引策略
- 需要实现RESTful API接口
