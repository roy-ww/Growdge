# US006: 查看和管理知识来源

## 用户故事
作为用户，我想要查看和管理我的知识来源，以便我可以了解我的学习空间包含哪些内容。

## 功能描述
用户可以查看、编辑、删除和管理添加到学习空间中的各种知识来源（网页、文本、PDF等）。

## 详细需求

### 1. 查看知识来源列表
- 用户可以查看指定学习空间下的所有知识来源
- 显示来源类型（网页链接、文本内容、PDF文件等）
- 显示来源的基本信息（标题、创建时间、大小等）
- 按添加时间排序，支持自定义排序方式
- 支持分页查询

### 2. 筛选和搜索
- 按来源类型筛选（网页、文本、PDF）
- 按关键词搜索来源内容
- 按创建时间范围筛选
- 按文件大小筛选

### 3. 查看来源详情
- 查看单个知识来源的详细信息
- 对于网页来源，显示原始URL和提取的标题
- 对于文本来源，显示文本预览
- 对于PDF来源，显示文件信息和页面数量

### 4. 编辑来源信息
- 修改来源的标题或描述
- 更新来源的分类标签
- 重新处理来源内容（如重新解析PDF）

### 5. 删除来源
- 删除不再需要的知识来源
- 删除时需要确认操作
- 删除来源时应同时清理相关的AI生成内容

### 6. 批量操作
- 支持批量删除多个来源
- 支持批量重新处理内容

## 验收标准
1. 用户能够查看学习空间下的所有知识来源
2. 能够按不同类型筛选和搜索来源
3. 能够查看单个来源的详细信息
4. 能够编辑来源的基本信息
5. 能够删除不需要的来源
6. 批量操作功能正常工作

## 非功能性需求
1. 响应时间：列表查询在1秒内返回结果
2. 支持10000个知识来源的管理
3. 支持高并发访问
4. 数据持久化存储到PostgreSQL

## 技术实现考虑
- 后端相关，与前端无关
- 需要考虑数据库查询性能优化
- 需要实现适当的索引策略
- 需要实现RESTful API接口
- 需要考虑删除操作的数据一致性
