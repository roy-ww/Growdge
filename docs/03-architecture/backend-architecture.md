# NoteLM学习平台后端技术方案

## 1. 项目概述

### 1.1 项目目标
构建一个以笔记为虚拟概念载体的学习平台，支持多源内容整合、AI驱动问答、聊天机制、学习笔记、知识卡片、思维导图和测验生成功能的后端服务。

### 1.2 核心功能
- 知识空间管理
- 多源内容管理（网页、文本、PDF）
- AI驱动的问答、聊天、知识卡片、测验和思维导图生成
- 学习笔记管理
- 学习资料存储

### 1.3 技术架构
- 后端服务：基于Spring Boot的微服务架构
- 数据库：PostgreSQL
- 文件存储：本地存储与对象存储服务
- AI服务：集成阿里通义千问API
- API设计：RESTful API

## 2. 技术栈选型

### 2.1 后端框架
- **语言**: Java 17
- **框架**: Spring Boot 3.x
- **Web框架**: Spring MVC
- **数据访问**: Spring Data JPA
- **数据库**: PostgreSQL 14+
- **API文档**: Swagger/OpenAPI 3.0
- **缓存**: Redis
- **消息队列**: RabbitMQ/Redis Streams
- **安全**: Spring Security + JWT
- **文件处理**: Apache PDFBox, JSoup, Apache Tika
- **Markdown处理**: markdown-java 或 commonmark-java

### 2.2 AI服务集成
- **大模型**: 阿里通义千问（Qwen）
- **向量数据库**: Pinecone/PgVector
- **内容检索**: Elasticsearch

### 2.3 部署方案
- **容器化**: Docker
- **编排**: Docker Compose / Kubernetes
- **反向代理**: Nginx
- **监控**: Prometheus + Grafana
- **日志**: ELK Stack

## 3. 数据库设计

### 3.1 数据库表结构DDL

```sql
-- 学习空间表
CREATE TABLE learning_spaces (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    name VARCHAR(100) NOT NULL,

    user_id BIGINT NOT NULL,

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

);

-- 知识来源表
CREATE TABLE knowledge_sources (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (learning_space_id) REFERENCES learning_spaces(id)
);

-- AI问答记录表
CREATE TABLE ai_questions (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,

    question TEXT NOT NULL,

    FOREIGN KEY (learning_space_id) REFERENCES learning_spaces(id)

-- 聊天会话表

    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,

    status VARCHAR(20) DEFAULT 'ACTIVE',

    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (learning_space_id) REFERENCES learning_spaces(id)
);

-- 聊天消息表
CREATE TABLE chat_messages (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    chat_session_id BIGINT NOT NULL,

    content TEXT NOT NULL,

    FOREIGN KEY (chat_session_id) REFERENCES chat_sessions(id)
);

-- 学习笔记表
CREATE TABLE learning_notes (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    learning_space_id BIGINT,
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL,
    content_format VARCHAR(20) DEFAULT 'MARKDOWN', -- PLAIN, MARKDOWN

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 知识卡片表
CREATE TABLE knowledge_cards (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    learning_space_id BIGINT NOT NULL,
    question TEXT NOT NULL,
    answer TEXT NOT NULL,
    card_type VARCHAR(20) DEFAULT 'QA', -- QA(问答), FLASHCARD(闪卡)
    difficulty_level INTEGER DEFAULT 1, -- 1-5级难度
    review_count INTEGER DEFAULT 0,
    last_reviewed_at TIMESTAMP,
    next_review_at TIMESTAMP,
    status VARCHAR(20) DEFAULT 'ACTIVE',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (learning_space_id) REFERENCES learning_spaces(id)
);

-- 测验表
CREATE TABLE quizzes (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    learning_space_id BIGINT NOT NULL,
    title VARCHAR(255) NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (learning_space_id) REFERENCES learning_spaces(id)
);

-- 测验题目表
CREATE TABLE quiz_questions (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    quiz_id BIGINT NOT NULL,
    question_text TEXT NOT NULL,
    question_type VARCHAR(20) DEFAULT 'MULTIPLE_CHOICE',
    options JSONB, -- JSON格式存储选择题选项
    correct_answer VARCHAR(10),
    explanation TEXT,
    difficulty_level INTEGER DEFAULT 1, -- 1-5级难度
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (quiz_id) REFERENCES quizzes(id)
);

-- 思维导图表
CREATE TABLE mind_maps (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    learning_space_id BIGINT NOT NULL,
    title VARCHAR(255) NOT NULL,
    description TEXT,
    nodes JSONB, -- JSON格式存储导图节点
    edges JSONB, -- JSON格式存储节点关系
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (learning_space_id) REFERENCES learning_spaces(id)
);

-- 学习资料表
CREATE TABLE study_materials (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    learning_space_id BIGINT NOT NULL,
    material_type VARCHAR(20) NOT NULL, -- AI_ANSWER, KNOWLEDGE_CARD, MIND_MAP, QUIZ, CUSTOM
    title VARCHAR(255) NOT NULL,
    content TEXT,
    source_ref_id BIGINT, -- 关联来源ID
    tags JSONB, -- JSON格式存储标签

    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

CREATE TABLE users (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,

    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
```

## 4. AI服务配置

### 4.1 大模型配置管理
- **模型提供商**: 阿里云通义千问
- **配置管理**: 所有大模型配置信息统一管理在项目配置文件中
- **配置内容**:
  - API地址 (apiUrl)
  - 模型类型 (modelName)
  - API密钥 (apiKey)

### 4.2 配置文件示例 (application.yml)
```yaml
# AI服务配置
ai:
  provider: "aliyun"  # 服务提供商
  qwen:
    api-url: https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation
    model-name: "qwen-max"  # 或 qwen-plus, qwen-turbo
    api-key: ${ALIBABA_API_KEY:your-api-key-here}  # 支持环境变量和默认值
    timeout: 60s  # 请求超时时间
    max-tokens: 2000  # 最大返回token数
    temperature: 0.7  # 创造性参数
```

### 4.3 配置类实现
- **AIConfig.java**: 配置类，使用@Value注解读取配置文件
- **AIClient.java**: 封装对阿里通义千问API的调用
- **支持切换**: 通过配置文件轻松切换到其他大模型提供商

## 6. 服务架构设计

### 6.1 微服务划分
- **用户服务 (User Service)**: 用户认证、权限管理
- **学习空间服务 (Learning Space Service)**: 学习空间管理
- **知识来源服务 (Knowledge Source Service)**: 知识来源管理、内容提取
- **AI服务 (AI Service)**: AI问答、知识卡片、测验、思维导图生成
- **聊天服务 (Chat Service)**: 聊天会话管理、消息处理
- **笔记服务 (Notes Service)**: 学习笔记管理
- **学习资料服务 (Study Material Service)**: 学习资料管理
- **文件服务 (File Service)**: 文件上传、存储、处理

### 6.2 服务间通信
- **同步调用**: RESTful API + HTTP协议
- **异步通信**: 消息队列（RabbitMQ/Redis Streams）
- **服务发现**: Eureka/Consul
- **API网关**: Spring Cloud Gateway

### 6.3 数据流设计
1. 用户创建学习空间 → 学习空间服务创建记录
2. 用户添加知识来源 → 文件服务处理上传 → 知识来源服务存储
3. 用户请求AI功能 → AI服务调用阿里通义千问API → 处理结果并存储
4. 用户发起聊天 → 聊天服务处理会话 → AI服务提供回答（不涉及聊天历史检索）
5. 用户创建笔记 → 笔记服务存储 → 支持Markdown解析
6. 内容生成（卡片、测验、导图）→ 学习资料服务统一管理

## 7. 业务逻辑设计

### 7.1 学习空间管理
- 创建时验证名称唯一性
- 支持软删除（状态标记）
- 自动统计关联的来源和资料数量

### 7.2 知识来源处理
- 网页内容提取（使用Jsoup解析HTML）
- PDF内容解析（使用Apache PDFBox）
- 文本内容清洗和预处理
- 内容向量化存储（用于AI检索）

### 7.3 AI功能实现
- 问答功能：检索相关知识来源 → 构造提示词 → 调用阿里通义千问API → 验证和格式化结果
- 聊天功能：维护对话上下文（仅当前会话内） → 检索相关知识来源 → 构造提示词 → 调用阿里通义千问API → 返回格式化结果（注意：不实现跨会话内容检索）
- 知识卡片生成：分析知识来源 → 提取知识点 → 生成问答对 → 质量验证
- 测验生成：分析知识来源 → 提取关键概念 → 生成选择题 → 提供正确答案和解释
- 思维导图生成：分析知识结构 → 提取概念层级 → 构建知识关系 → 生成可视化结构

### 7.4 聊天机制实现（更新）
- 会话管理：创建、维护、关闭聊天会话
- 上下文管理：仅维护当前会话内的对话历史和学习空间上下文（不实现跨会话内容检索）
- 知识检索：基于当前空间内容检索相关信息
- 消息处理：处理用户输入并生成AI回复
- 引用标注：在回复中标注使用的信息来源
- 记录存储：保存聊天记录以供会话内使用，但不提供聊天历史检索功能

### 7.5 学习笔记实现
- 笔记管理：创建、编辑、删除、查询笔记
- Markdown格式：支持完整的Markdown语法解析和渲染
- 内容安全：防范Markdown内容中的XSS攻击
- 标签系统：支持笔记标签分类

### 7.6 学习资料管理
- 统一存储不同类型的学习资料
- 支持标签和分类管理
- 提供全文搜索能力

## 8. AI服务集成设计

### 8.1 阿里通义千问集成
- **API调用方式**: RESTful API调用
- **认证方式**: 通过API Key进行认证
- **请求格式**: JSON格式请求体
- **响应处理**: 解析JSON响应并提取答案

### 8.2 提示词工程
- **上下文构建**: 根据学习空间内容构建适当的上下文
- **多轮对话管理**: 维护对话历史，提供给模型以保持一致性
- **内容引用**: 在生成的回答中引用相关的知识来源

### 8.3 配置管理实现

## 9. 安全方案

### 9.1 认证授权
- **认证方式**: JWT Token + OAuth2
- **用户认证**: 登录验证、Token刷新
- **权限控制**: 基于角色的访问控制（RBAC）
- **API限流**: 防止滥用（Rate Limiting）

### 9.2 数据安全
- **数据加密**: 敏感数据存储加密
- **传输安全**: HTTPS协议
- **访问控制**: 基于用户ID的资源访问验证
- **文件安全**: 文件类型验证、病毒扫描

### 9.3 API安全
- **输入验证**: 请求参数校验
- **SQL注入防护**: 使用参数化查询
- **XSS防护**: 输出内容转义，特别是Markdown内容
- **CSRF防护**: Token验证

### 12.2 命名规范
- **类名**: 驼峰命名，首字母大写 (LearningSpaceService)
- **方法名**: 驮峰命名，首字母小写 (createLearningSpace)
- **常量**: 全大写，下划线分隔 (DEFAULT_PAGE_SIZE)
- **包名**: 全小写 (com.notelm.service)

### 12.3 注释要求
- 类和公共方法必须有JavaDoc注释
- 复杂逻辑需要行内注释
- 接口需要详细说明参数、返回值和异常

### 12.4 测试规范
- 单元测试覆盖率不低于80%
- 集成测试覆盖主要业务流程
- 使用Mockito进行依赖模拟
- 使用TestContainers进行集成测试
- 针对Markdown解析功能编写专门的安全测试
