# NotebookLM 界面克隆

这是一个基于原版NotebookLM界面设计的HTML页面克隆，包含三个主要页面：主页、笔记本详情页和笔记列表页，具有现代化的深色主题和响应式设计。

## 功能特性

### 🎨 界面设计
- **深色主题**：现代化的深色界面设计
- **三栏布局**：来源面板、对话面板、Studio面板
- **响应式设计**：支持桌面和移动设备
- **流畅动画**：平滑的过渡和悬停效果

### 📁 来源面板
- 添加和探索来源
- 选择所有来源功能
- 来源列表管理
- 复选框状态同步

### 💬 对话面板
- 内容展示区域
- 保存到笔记功能
- 操作按钮（添加笔记、音频概览、思维导图）
- 智能输入框
- 建议提示
- 实时消息发送

### 🎯 Studio面板
- 六种功能卡片：音频概览、视频概览、思维导图、报告、闪卡、测验
- 最近活动列表
- 浮动添加按钮
- 实时状态更新

## 技术栈

- **HTML5**：语义化标记
- **CSS3**：现代样式和动画
- **JavaScript (ES6+)**：交互功能
- **Font Awesome**：图标库

## 使用方法

### 访问页面
1. **主页**：打开 `home.html` 查看笔记本列表和精选内容
2. **笔记本详情页**：打开 `index.html` 查看具体的笔记本内容
3. **笔记列表页**：打开 `notes-list.html` 查看列表视图的笔记管理

### 本地服务器
```bash
# 使用Python
python -m http.server 8000

# 使用Node.js
npx serve .
```

然后访问：
- 主页：`http://localhost:8000/home.html`
- 详情页：`http://localhost:8000/index.html`
- 列表页：`http://localhost:8000/notes-list.html`

## 自定义

### 修改主题颜色
在 `styles.css` 中修改CSS变量：
```css
:root {
    --primary-color: #4A90E2;
    --background-color: #1a1a1a;
    --surface-color: #2a2a2a;
}
```

### 添加新功能
在 `script.js` 中添加新的处理函数：
```javascript
function newFeature() {
    // 新功能实现
}
```
